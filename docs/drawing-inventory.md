# Spis rysunków Matyldy

Ten dokument zapisuje znaczenie elementów widocznych na rysunkach źródłowych. Identyfikatory mają format `numerRysunku + litera`, np. `1A`.

Opisy pogrupowane według zastosowania znajdują się w `docs/assets/`.

## Rysunek 1 — `source-drawings/1.jfif`

| Identyfikator | Element | Rola w grze |
| --- | --- | --- |
| `1A` | Słońce | Element tła. |
| `1B` | Chmury | Element tła. |
| `1C` | Drzewo | Dekoracja terenu. |
| `1D` | Plazma, którą pluje smok | Atak smoka / pocisk gracza. |
| `1E` | Smok stojący na trawie | Główna postać towarzysząca chłopcu. |
| `1F` | Chłopiec | Główny bohater gry. |
| `1G` | Jajo kupione w mieście | Przedmiot fabularny; z niego wykluwa się smok. |
