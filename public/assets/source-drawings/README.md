# Oryginalne rysunki Matyldy

Te pliki są źródłowymi, niezmienianymi zdjęciami rysunków. Nie należy ich nadpisywać ani przycinać.

| Plik | Zawartość |
| --- | --- |
| `1.jfif` | Bohater, jego smok, jajo, plazma i łąka. |
| `2.jfif` | Oswajanie smoka. |
| `3.jfif` | Lot smoka z bohaterem oraz łowcy smoków. |
| `4.jfif` | Uwolnienie smoka z klatki. |
| `5.jfif` | Morska walka ze statkiem łowców. |
| `6.jfif` | Schwytanie smoka w sieć. |
| `7.jfif` | Dodatkowa scenka oswajania smoka. |
| `8.jfif` | Lodowy Smok Alfa, uwalniany w finale szóstego poziomu. |

Dokładny spis identyfikatorów jest w `docs/drawing-inventory.md`, a podział według zastosowania — w `docs/assets/`.
