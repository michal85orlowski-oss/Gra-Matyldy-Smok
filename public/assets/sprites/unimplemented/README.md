# Zestaw postaci — do późniejszego wdrożenia

`matylda-characters-sprite-sheet-v1.png` zawiera cztery przygotowane grafiki na jednolitym różowym tle technicznym:

1. chłopca bez broni;
2. smoka z chłopcem na grzbiecie;
3. łowcę z łukiem;
4. drewniany miotacz włóczni.

Grafiki są materiałem roboczym inspirowanym rysunkami Matyldy. Nie są obecnie częścią wdrożonego renderowania gry. Przed wykorzystaniem należy przygotować przezroczyste warianty każdego sprite'a i zaakceptować ich wygląd.
